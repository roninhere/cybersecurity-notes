# Cross-Site Scripting (XSS)

Technical notes on cross-site scripting vulnerabilities, browser execution contexts, injection techniques, detection methods, and prevention.

## Topics

* XSS Fundamentals
* Reflected XSS
* Stored XSS
* DOM-Based XSS
* HTML, Attribute, and JavaScript Contexts
* JavaScript Execution and Parsing
* Context-Aware Payload Construction
* Input Validation and Output Encoding
* Content Security Policy (CSP)
* Filter Bypasses
* Detection and Testing Methodology
* Prevention and Mitigation

## Purpose

Build a comprehensive understanding of cross-site scripting, including how untrusted input can lead to unintended script execution in a browser, how execution contexts influence exploitability, and how secure coding practices prevent these vulnerabilities.
