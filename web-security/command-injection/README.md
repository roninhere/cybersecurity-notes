# OS Command Injection

Technical notes on operating system command injection vulnerabilities, shell behavior, detection techniques, exploitation methods, and prevention.

## Topics

* Command Injection Fundamentals
* Shell Command Execution
* Command Separators and Operators
* Blind Command Injection
* Time-Based Detection
* Output Redirection
* Out-of-Band Techniques
* Operating System Differences
* Input Validation and Filter Bypasses
* Detection and Testing Methodology
* Prevention and Mitigation

## Purpose

Build a comprehensive understanding of OS command injection, including how unsafe command construction can allow untrusted input to influence system-level execution, how vulnerabilities can be identified, and how secure programming practices can prevent them.
